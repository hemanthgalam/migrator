API Overview

The SQL to MongoDB Migration API provides comprehensive endpoints for migrating data from SQL databases to MongoDB collections with real-time Change Data Capture capabilities.

Base URL
http://localhost:3000/api
Content Type
application/json

Supported Databases

SQL Sources
  • MySQL 5.7+
  • PostgreSQL 9.6+
  • SQL Server 2012+
MongoDB Target
  • MongoDB 3.6+
  • Atlas Compatible
  • Replica Sets
CDC Features
  • Real-time Sync
  • Batch Processing
  • Error Recovery

Authentication

Currently, the API does not require authentication for development purposes. For production deployments, consider implementing API key authentication.

Future Enhancement: API key authentication can be added using the X-API-Key header.

SQL Database Endpoints

POST /api/sql/connect

Connect to a SQL database (MySQL, PostgreSQL, or SQL Server)

Request Body:
{
  "type": "mysql",
  "host": "localhost",
  "port": 3306,
  "database": "mydb",
  "username": "user",
  "password": "password"
}
GET /api/sql/tables/{connectionKey}

Get all tables from the connected SQL database

GET /api/sql/columns/{connectionKey}/{tableName}

Get column information for a specific table

POST /api/sql/preview/{connectionKey}

Preview data from a table with optional column selection

Request Body:
{
  "tableName": "users",
  "selectedColumns": ["id", "name", "email"],
  "limit": 10
}
POST /api/sql/data/{connectionKey}

Get all data from a table with optional filtering

Request Body:
{
  "tableName": "users",
  "selectedColumns": ["id", "name", "email"],
  "whereClause": "status = 'active'"
}
DELETE /api/sql/disconnect/{connectionKey}

Close the connection to the SQL database

MongoDB Endpoints

POST /api/mongo/connect

Connect to a MongoDB database

Request Body:
{
  "host": "localhost",
  "port": 27017,
  "database": "mydb",
  "username": "user",
  "password": "password",
  "authSource": "admin"
}
GET /api/mongo/test/{connectionKey}

Test if the MongoDB connection is active

GET /api/mongo/collections/{connectionKey}

Get all collections from the MongoDB database

POST /api/mongo/insert/{connectionKey}

Insert documents into a MongoDB collection

Request Body:
{
  "collectionName": "users",
  "documents": [
    {"name": "John Doe", "email": "john@example.com"},
    {"name": "Jane Smith", "email": "jane@example.com"}
  ]
}
DELETE /api/mongo/disconnect/{connectionKey}

Close the connection to the MongoDB database

Migration Endpoints

POST /api/migration/migrate

Perform a one-time data migration from SQL to MongoDB

Request Body:
{
  "sqlConnectionKey": "mysql-localhost-mydb",
  "mongoConnectionKey": "mongo-localhost-mydb",
  "tableName": "users",
  "collectionName": "users_collection",
  "selectedColumns": ["id", "name", "email", "created_at"],
  "whereClause": "status = 'active'",
  "batchSize": 1000
}
GET /api/migration/status/{migrationId}

Get the status of a migration job (placeholder for future enhancement)

Change Data Capture Endpoints

POST /api/cdc/start

Start a new CDC polling job for real-time data synchronization

Request Body:
{
  "sqlConnectionKey": "mysql-localhost-mydb",
  "mongoConnectionKey": "mongo-localhost-mydb",
  "tableName": "users",
  "collectionName": "users_sync",
  "selectedColumns": ["id", "name", "email", "updated_at"],
  "timestampColumn": "updated_at",
  "primaryKeyColumn": "id",
  "pollingInterval": 5000,
  "batchSize": 1000,
  "whereClause": "status = 'active'"
}
POST /api/cdc/test

Test CDC configuration before starting a job (dry run)

Request Body:
{
  "sqlConnectionKey": "mysql-localhost-mydb",
  "tableName": "users",
  "timestampColumn": "updated_at",
  "primaryKeyColumn": "id",
  "selectedColumns": ["id", "name", "email"],
  "whereClause": "status = 'active'"
}
GET /api/cdc/jobs

Get all active and paused CDC jobs

GET /api/cdc/status/{jobId}

Get detailed status information for a specific CDC job

GET /api/cdc/stats/{jobId}

Get statistics for a specific CDC job

POST /api/cdc/pause/{jobId}

Pause a running CDC job

POST /api/cdc/resume/{jobId}

Resume a paused CDC job

POST /api/cdc/stop/{jobId}

Stop and remove a CDC job permanently

PUT /api/cdc/update/{jobId}

Update configuration for an existing CDC job

Request Body:
{
  "pollingInterval": 10000,
  "batchSize": 500,
  "whereClause": "status IN ('active', 'pending')"
}

Complete Examples

Example 1: One-time Migration

# 1. Connect to SQL Database
curl -X POST http://localhost:3000/api/sql/connect \
  -H "Content-Type: application/json" \
  -d '{
    "type": "mysql",
    "host": "localhost",
    "database": "ecommerce",
    "username": "user",
    "password": "password"
  }'

# Response: {"success": true, "connectionKey": "mysql-localhost-ecommerce"}

# 2. Connect to MongoDB
curl -X POST http://localhost:3000/api/mongo/connect \
  -H "Content-Type: application/json" \
  -d '{
    "host": "localhost",
    "database": "ecommerce_mongo"
  }'

# Response: {"success": true, "connectionKey": "mongo-localhost-ecommerce_mongo"}

# 3. Perform Migration
curl -X POST http://localhost:3000/api/migration/migrate \
  -H "Content-Type: application/json" \
  -d '{
    "sqlConnectionKey": "mysql-localhost-ecommerce",
    "mongoConnectionKey": "mongo-localhost-ecommerce_mongo",
    "tableName": "users",
    "collectionName": "users",
    "selectedColumns": ["id", "name", "email", "created_at"],
    "whereClause": "status = \"active\"",
    "batchSize": 1000
  }'

Example 2: Real-time CDC Setup

# 1. Test CDC Configuration
curl -X POST http://localhost:3000/api/cdc/test \
  -H "Content-Type: application/json" \
  -d '{
    "sqlConnectionKey": "mysql-localhost-ecommerce",
    "tableName": "orders",
    "timestampColumn": "updated_at",
    "primaryKeyColumn": "id",
    "selectedColumns": ["id", "user_id", "total", "status", "updated_at"]
  }'

# 2. Start CDC Job
curl -X POST http://localhost:3000/api/cdc/start \
  -H "Content-Type: application/json" \
  -d '{
    "sqlConnectionKey": "mysql-localhost-ecommerce",
    "mongoConnectionKey": "mongo-localhost-ecommerce_mongo",
    "tableName": "orders",
    "collectionName": "orders_sync",
    "selectedColumns": ["id", "user_id", "total", "status", "updated_at"],
    "timestampColumn": "updated_at",
    "primaryKeyColumn": "id",
    "pollingInterval": 5000,
    "batchSize": 100
  }'

# Response: {"success": true, "jobId": "uuid-here", "message": "Polling job started successfully"}

# 3. Monitor CDC Job
curl http://localhost:3000/api/cdc/stats/uuid-here

Error Handling

HTTP Status Codes

Status Code Description Example
200 Success Request completed successfully
400 Bad Request Missing required parameters
404 Not Found Job or resource not found
500 Internal Server Error Database connection failed

Error Response Format

{
  "error": "Connection failed: Access denied for user 'user'@'localhost'"
}

Success Response Format

{
  "success": true,
  "message": "Operation completed successfully",
  "data": { /* response data */ }
}
